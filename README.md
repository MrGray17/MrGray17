## 👋 A little about me

I'm **El Yazid Hammoubel**, a software engineering student at **ENSA Kénitra, Morocco**.

I enjoy building software where the interesting problems live below the interface: **concurrency, persistence, correctness, failure recovery, and trust boundaries**. I'm especially interested in **backend and distributed systems**, with a growing focus on **cloud/platform engineering and AI infrastructure**.

> **My approach:** build something real, understand why it works, test what can break, and improve the design with evidence.

- 🔭 **Building:** Barista, a Java/Spring Boot job queue and workflow-engine project.
- 🛡️ **Exploring:** safe execution and verification of AI-generated code through Mirage.
- 🧠 **Learning:** AI engineering fundamentals, cloud/platform concepts, and deeper systems design.
- 🧰 **Working with:** Java, TypeScript, Go, Python, PostgreSQL, Docker, Linux, and Git.

<a id="featured-work"></a>
## 🚀 Featured work

<a href="https://github.com/MrGray17/Mirage">
  <img src="./assets/feature-mirage-v2.svg" width="100%" alt="Explore Mirage, a security runtime for untrusted AI coding agents" />
</a>

**[Mirage](https://github.com/MrGray17/Mirage)** — A Go-based runtime that isolates an untrusted coding agent, independently inspects its final changes, checks them against a deterministic contract, and allows only authorized effects to reach a real workspace. The project documents its security model, verification process, and limitations.

<a href="https://github.com/MrGray17/barista">
  <img src="./assets/feature-barista-v2.svg" width="100%" alt="Explore Barista, a Java and Spring Boot job queue in development" />
</a>

**[Barista](https://github.com/MrGray17/barista)** — An **in-progress** backend systems project built with Java 21, Spring Boot, PostgreSQL, and JDBC. I'm using it to learn durable job storage, retry semantics, concurrent workers, transactional boundaries, and testing. It's a learning-driven build, not a finished production service.
